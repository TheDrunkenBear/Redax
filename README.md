# Redax

Obsidian-подобный блочный редактор заметок, который работает в браузере без установки и сборки — на любой ОС.

## Возможности

- **Блочный редактор**: заголовки трёх уровней и абзацы; Enter создаёт новый блок, Backspace на пустом блоке удаляет его, меню «+» слева от блока добавляет или удаляет блоки.
- **Заметки — это Markdown-файлы**: первый заголовок (H1) задаёт имя файла; переименование происходит автоматически.
- **Работа с файловой системой**: в Chrome и Edge можно выбрать рабочую папку (vault) — заметки читаются и сохраняются как `.md`-файлы прямо в ней, включая подпапки. В остальных браузерах заметки хранятся локально в браузере (localStorage).
- **Корзина**: удалённые заметки группируются по папкам и восстанавливаются в один клик (в файловом режиме — подпапка `.trash`).
- **Настройки**: размер шрифта, четыре гарнитуры (книжная, гротеск, моно, «машинка»), показ расширения `.md`.
- **Адаптивная вёрстка**: на узких экранах боковая панель накладывается поверх текста.

## Установка как отдельного приложения (PWA)

Redax можно установить как самостоятельное приложение с собственным окном и иконкой:

1. Откройте Redax по http(s)-адресу в Chrome или Edge (например, через локальный сервер — см. «Запуск»).
2. Нажмите значок установки в адресной строке (или Меню → «Сохранить и поделиться» → «Установить Redax»).
3. Приложение появится в доке/меню «Пуск», откроется в отдельном окне и будет работать офлайн — оболочка кешируется сервис-воркером.

## Запуск

Установка не нужна. Любой из вариантов:

- Открыть `index.html` двойным кликом — редактор заработает сразу (хранение в браузере).
- Для работы с реальными папками запустите любой статический сервер и откройте страницу в Chrome/Edge:

```bash
python3 -m http.server 8642
```

…и откройте <http://localhost:8642>.

## Структура

```
index.html    — каркас интерфейса
styles.css    — дизайн-токены и стили (палитра «шалфей»)
js/vault.js   — слой хранения: localStorage и File System Access API
js/app.js     — состояние, редактор блоков, панель, корзина, настройки
```
